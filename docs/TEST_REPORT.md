# Կմախքի ստուգումների հաշվետվություն

Ամսաթիվ՝ 17.10.2026, Asia/Yerevan։ Վիճակ՝ առաջին տեղադրվող տարբերակի տեղային հիմք։ **Վերջնական ճամփորդական ծրագիրը պատրաստ չի հայտարարվում։**

## Ինչ է արված

Գրված են հայերեն միջերեսը, մեկ փորձնական օրվա երկու կանգառը, Leaflet քարտեզը, դիրքի հարցումը, կանգառի Google Maps հղումները՝ տեսանելի ռեժիմի ընտրությամբ, մասնավոր fragment-ի տեղային ընդունումը, տվյալների թարմացումը, offline տեքստի հիմքը, manifest-ը և պատկերակները։ Հասցեներ չկան հանրային ֆայլերում։ GitHub repository/Pages դեռ չի ստեղծվել։

## Ինչ է ստուգված

Փորձարկման համակարգ՝ Windows build **10.0.26200**, Node.js **22.23.3**, desktop Microsoft Edge **155.0.4283.45**՝ Playwright-ով։ Ոչ իրական Android/iPhone, ոչ սարքի տեղադրման ապացույց։

- `npm test`՝ **7/7 PASS**։ Անհայտ կոորդինատները չեն դառնում 0,0, Google Maps URL-ները կոդավորվում են, Europe/Paris-ի 25.10.2026 DST անցումը ճիշտ է, մասնավոր fragment-ը վավերացվում է, սխալ JSON կառուցվածքը և ներդրված սխալ տիպերը մերժվում են, վնասակար source URL-ները չեն բացվում։
- `tools/browser-smoke.mjs`՝ **12/12 PASS**։ Տվյալների ցուցադրում, նավիգացիայի ռեժիմի ընտրություն, ենթապանակի service worker, 320/375/800/900/1440 px առանց հորիզոնական ոլորման, ամբողջ էկրանից browser Back, սիմուլացված GPS և մերժում, սինթետիկ մասնավոր հասցեի պահում/fragment-ի հեռացում, վավեր/անվավեր թարմացումներ, offline reload, անկախ դիտարկչային պահոց, միայն հավելվածի ֆայլերի cache։ JavaScript page errors՝ 0։
- Քարտեզի իրական OSM tile-երը երևացել են desktop screenshot-ում։ Կանգառների միջև երթուղի ներկայացնող ուղիղ գծեր չեն ավելացվել։
- Leaflet JS/CSS SHA-256-ը համընկնում է պաշտոնական էջի SRI արժեքներին։
- `tools/privacy-check.mjs`՝ ստուգում է բոլոր հանրային տեքստային ֆայլերը 02-ում նշված իրական երեք հասցեների և դրանց URL-կոդավորված տարբերակների նկատմամբ՝ առանց հասցեները պահելու/տպելու։ Բնօրինակ 00/01/02 ֆայլերը փաթեթի մաս չեն։ Սա բոլոր հնարավոր գաղտնիքների համընդհանուր սկաներ չէ։

Կրկնելի ապացույցներ՝ `verification-browser.json`, `verification-core.txt`, տեղային `artifacts/desktop.png` և `artifacts/mobile.png`։ Screenshots-ը ZIP-ում չեն ներառվում։ Տեխնիկական պաշտոնական աղբյուրները՝ [SOURCES.md](SOURCES.md), ստուգման ամսաթիվ՝ 17.10.2026։

## Վերանայման ուղղումները

1. Browser փորձը վերարտադրեց արդեն բաց էջին միայն `#homes` ավելացնելիս հասցեի չպահպանումը։ Ավելացվեց hashchange-ի մշակում։ Նույն փորձը հետո PASS է։
2. Անկախ reviewer-ը հայտնաբերեց ներդրված սխալ դաշտով թարմացման վտանգը։ Նախ գրանցվեց FAIL թեստ, ավելացվեց ներդրված կառուցվածքի վավերացում, իսկ պահպանումը տեղափոխվեց հաջող ցուցադրումից հետո։ Unit և browser ստուգումները PASS են։
3. Reviewer-ը նշեց `to_next.mode`-ի իմաստային երկիմաստությունը։ 02 Բ4-ի պահանջած սկզբնական արժեքը պահպանվել է, բայց ռեժիմը տեսանելի և ընտրելի է։ Սխեման չի փոխվել։
