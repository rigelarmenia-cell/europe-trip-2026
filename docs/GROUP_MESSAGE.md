# Խմբին ուղարկելու տեքստ

Մեր ճամփորդության միջանկյալ ծրագիրը՝ https://rigelarmenia-cell.github.io/europe-trip-2026/

Android-ում բացեք միայն Chrome-ով։ Եթե չունեք՝ տեղադրեք Play Store-ից։ Սեղմեք ⋮ → «Установить и создать ярлык»։ Անգլերեն՝ Install and create shortcut → Install (ՀԱՍՏԱՏՎԱԾ՝ Google-ի հրահանգով, 17.10.2026, https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid)։

Samsung Internet-ով մի տեղադրեք։ Եթե Play Protect-ի պատուհան է հայտնվում՝ OK, ապա բացեք Chrome-ով։

iPhone-ում՝ Safari → Share → Add to Home Screen → Open as Web App, եթե կա → Add։

Կազմակերպչի մասնավոր հղումը բացեք միայն ձեր հեռախոսում և ստուգեք «Տուն»-ի հասցեն նաև ծրագրի պատկերակից բացելիս։ Հղումը խմբից դուրս մի տարածեք։ Հասցեներ պարունակող screenshot մի ուղարկեք։

Առաջին անգամ բացեք ինտերնետով։ Հետո անջատեք կապը, փակեք ու վերաբացեք. տեքստը և օդանավակայանները պետք է մնան։ Քարտեզի նոր հատվածները և Google Maps-ը կապ են պահանջում։

Օրերի պլանը դեռ պատրաստվում է։ Օդանավակայանային տվյալները միջանկյալ են. կարդացեք պիտակներն ու զգուշացումները։ Իրական հեռախոսների վերջնական ստուգումը դեռ չի ավարտվել։
