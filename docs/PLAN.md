# Առաջին կմախքի պլան

Հիմք՝ սեփականատիրոջ 02 առաջադրանքը և «Սկսիր կմախքից» ուղիղ հրահանգը։ Այս փուլում իրականացվում է 17.10-ի առաջին տեղադրվող տարբերակի հիմքը, ոչ ամբողջ Փուլ Բ-ի ընդունումը։

Ընտրություն՝ սովորական HTML/CSS/ES modules, տեղային Leaflet 1.9.4, առանց build-ի և հավելվածային սերվերի։ React/Vite-ն կավելացներ հավաքման քայլ, CDN-ից Leaflet-ը՝ արտաքին մեկնարկային կախվածություն։ Միակ արտադրական կախվածությունը ֆիքսված Leaflet-ն է։

Ֆայլերը՝ `index.html`, `styles.css`, `app.js`, `lib/core.js`, `lib/map.js`, `sw.js`, `manifest.webmanifest`, `trip.json`, `icons/`, `vendor/leaflet/`։ UI-ն միայն կարդում է trip.json-ը։ Փորձնական նշումը՝ պայմանագրի գոյություն ունեցող title/notes դաշտերում, առանց նոր դաշտի։

1. URL-ների, անհայտ կոորդինատների, տեղական ամսաթվի և մասնավոր fragment-ի գործառութային թեստերը՝ նախ ձախողվող, հետո իրականացում։ Հրաման՝ `npm test`։
2. Հայերեն փոքր էկրանին ներդիրներ, լայն էկրանին ցանկ և քարտեզ։ GPS՝ միայն բացատրությունից և սեղմումից հետո, մերժումը չի արգելափակում պլանը։ Անհայտ թվերը null են։
3. Manifest, PNG պատկերակներ, հարաբերական ուղիներ՝ repository ենթապանակում աշխատելու համար։ Service worker-ը պահում է միայն հավելվածի ֆայլերը։ OSM tile-երը և լուսանկարները չի ներբեռնում offline-ի համար։
4. trip.json՝ ցանցից ստուգում, տեղային պահուստ, նոր տարբերակի հստակ առաջարկ։ Անվավեր նոր ֆայլը չի փոխարինում վերջին վավերին։ Հասցեների և տվյալների պահոցներն առանձին են։
5. Browser ստուգում՝ եթե հասանելի է, offline, resize, null-եր, սխալ JSON, GPS մերժում, մասնավոր հղման մաքրում և թարմացում։ Սրանք իրական Android/iPhone չեն։
6. README, աղբյուրներ և T01–T12 հաշվետվություն՝ բացերի բացահայտ նշումով։ Պատրաստի ZIP և GitHub Pages-ի քայլեր։

Ուշադրության կետեր՝ GitHub ենթապանակի scope, Safari-ի և տեղադրված ծրագրի պահոցների հնարավոր տարբերություն, անկանոն JSON, GPS թույլտվության մերժում, հին service worker, անհայտ ժամային տվյալներ։
