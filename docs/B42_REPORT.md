## Ինչ է արված

Կարդացված է artifacts/CODEX_B4-2_TASK.txt-ն ամբողջությամբ և կատարված է հիմնական առաջադրանքը՝ կոորդինատային բացերի լրացման հետ։ Սեփականատիրոջ նոր պահանջը գերակա է նախկին «գծեր չգծել» վարքի նկատմամբ։ Համապատասխան հին browser թեստը փոխվել է՝ safety շերտը անջատելիս օրվա գծերը մնում են։

Օրվա ընթացիկ հերթականությամբ՝ քայլքը կետագծով, metro/train-ը հոծ ուղիղ, bus/tram/taxi-ը paths.json-ից ճանապարհային երկրաչափությամբ կամ հստակ նշված ուղիղ fallback-ով։ Անհայտ/փոփոխված հատվածը բարակ մոխրագույն կետագիծ է։ Գունավորումը ճանաչում է Paris M1/M11, Barcelona L3/L4/L9, Rome B/B1-ը, չի օգտագործում to_next.color-ը որպես CSS։ Գույները պաշտոնական գունային ընտանիքներն են՝ թվային ցուցադրման ընտրված երանգներով, ոչ պաշտոնական hex-ի վկայական։

Սկզբում՝ հանրային home_station→առաջին կանգառ անհայտ գիծ, վերջում՝ վերջին կանգառ→home_station միայն to_next-ի առկայությամբ։ Մասնավոր հասցեները և airport_transfers-ը չեն մասնակցում։ Այցելած/բաց թողած կանգառները գծերից չեն հանվում։ Reorder-ի փոխված զույգը չի օգտագործում հին mode/km/min-ը։ Առանց կոորդինատի կետի երկու հարակից կապերը բացակայում են. հաջորդ վավեր կետի ելքային հատվածը մոխրագույն է, բացը չի կամրջվում։

Կա popup՝ տեսակ/գիծ/կմ/րոպե և մոտարկման նշում, քարտեզի տակ՝ լեգենդ։ Գծերի pane-ը կետերի, GPS-ի և զգուշության շերտից ցածր է։ «Քարտեզին»-ը հիմա միայն կենտրոնացնում է ընտրված կանգառին՝ պահպանելով մյուս կետերը։

tools/build-paths.mjs <trip.json> [output.json]՝ build-time OSRM driving հարցումներ միայն հանրային կանգառ/կայարան կոորդինատներով։ Յուրաքանչյուր բանալի՝ fromId>toId:mode, կայարանի ID՝ home:cityId, երկրաչափություն՝ առավելագույնը 200 [lat,lon] կետ։ Երկար գծերը նմուշառվում են մինչև 200, ուստի մոտարկում են։ Bus/tram-ի դեպքում սա փողոցային մոտարկում է, ոչ օպերատորի հաստատված երթագիծ։ Runtime-ում routing API չի կանչվում։

paths.json-ը բեռնվում է տեղային կայքից, ստուգվում տվյալների նկատմամբ և պահվում localStorage-ում՝ real/demo առանձին։ Վնասված/404 դեպքում՝ ուղիղ գծեր։ Offline՝ նախկին վավեր պահված գծեր։ Փոխված կետերին չհամապատասխանող գծերը մերժվում են։ Service worker-ի FILES-ում ավելացված է lib/paths.js-ը. փոփոխական paths.json-ը, ինչպես trip.json-ը, պահվում է տվյալների տեղային պահոցում, ոչ անփոփոխ shell cache-ում։ RELEASE՝ 0.4.0, ստորագրություն՝ Բ4.2 · 0.4.0։

Իրական v7-ի օրվա բոլոր հայտնի հատվածները walk են. bus/tram/taxi թեկնածու՝ 0, հետևաբար հրապարակվող paths.json={}։ Քայլքը գծվում է կետագծով ուղիղ կապերով, ոչ փողոցներով հաստատված քայլուղի։ Արտաքին OSRM-ը առանձին տեղային փորձով տվեց 82 կետ ունեցող ճանապարհ՝ երկու v7 հանրային կանգառի միջև. փորձնական ֆայլը չի հրապարակվում։

Իրական trip.json-ը և demo-trip.json-ը չեն փոխվել։ v7 SHA256՝ 6de3805ca1f0f09fb1c7e34e6a735c4fd5f68ecf556af8407b60df236a7f7034։ v9-ը կարդացվել է միայն Downloads/trip (7).json-ից, hash՝ 03230e614d83b8fc6e2262f4e2e994acd38cc8b21874dc0f47c0c28d88d9803f, չի հրապարակվում։

Բ4.1-ի ստուգման գործիքը, հորինված fixture generator-ը, խմբի հաղորդագրությունը և փաթեթավորման բացառումներն ընդգրկված են ընդհանուր հանձնումում։ Ինքը tests/fixtures/full-trip.json-ը ZIP-ում չի ներառվում։ Թեստերը կրկնելուց առաջ՝ node tools/make-full-fixture.mjs։
