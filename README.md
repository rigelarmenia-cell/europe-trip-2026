## Գործող GitHub Pages-ը թարմացնելու քայլերը

1. Բացեք `europe-trip-2026-B2-update.zip` → **Extract All / Извлечь всё**։
2. Բացեք [repository-ն](https://github.com/rigelarmenia-cell/europe-trip-2026), ընտրեք **Code**, ապա **main** ճյուղը։
3. Սեղմեք **Add file → Upload files**։
4. Քաշեք բացված ZIP-ի ներսի բոլոր ֆայլերն ու ենթապանակները։ ZIP-ը կամ արտաքին պանակը մի քաշեք։ Նույն ուղու նույնանուն ֆայլերը փոխարինվում են։ Մնացած հին ֆայլերը թողեք տեղում։ Ջնջվող ֆայլեր չկան։
5. Commit message-ում գրեք `Update travel app B2 0.2.0`։ Ընտրեք **Commit directly to the main branch**, ապա **Commit changes**։ Եթե ճյուղը պաշտպանված է, օգտագործեք նոր ճյուղ և pull request։
6. **Actions** բաժնում սպասեք Pages-ի հաջող ավարտին։ **Settings → Pages**-ում պետք է մնա `main / (root)`։ Նոր repository պետք չէ։
7. Chrome-ում բացեք [կայքը](https://rigelarmenia-cell.github.io/europe-trip-2026/)։ Եթե հայտնվի «Ծրագրի նոր տարբերակ կա», սեղմեք «Բացել նոր տարբերակը»։ Անհրաժեշտության դեպքում փակեք/վերաբացեք ինտերնետով։
8. Ստորև պետք է երևա `Բ2 · 0.2.0`, տվյալները՝ `2026-10-17-1`, «Օրերի պլանը դեռ պատրաստվում է», 6 տեղափոխություն, 4 չվերթ։ Իրական էջում փորձնական վահանակ չպետք է լինի։

## Տեղադրում

Android՝ **միայն Chrome**։ Եթե չկա՝ տեղադրեք Play Store-ից։ Բացեք հղումը → ⋮ → **«Установить и создать ярлык»** (սեփականատիրոջ տեսած ռուսերեն անվանումը)։ Անգլերեն՝ **Install and create shortcut → Install** — ՀԱՍՏԱՏՎԱԾ, [Google](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid), 17.10.2026։

Samsung Internet-ով մի տեղադրեք։ Play Protect-ի պատուհանի դեպքում սեղմեք **OK**, բացեք Chrome-ով։ Արգելափակման պատճառը ՉՍՏՈՒԳՎԱԾ է։

iPhone՝ Safari → Share → Add to Home Screen → Open as Web App, եթե կա → Add։ Իրական iPhone-ի ստուգումը բաց է։

Մասնավոր հղումը միայն խմբի ներսում է։ Բացեք այն օգտագործվող դիտարկչում, ստուգեք «Տուն»-ը նաև պատկերակից բացված ծրագրում։ Safari-ի և installed ծրագրի պահոցի փոխանցումը չստուգված է։ Fragment-ը հեռացվում է, հասցեները մնում են տվյալ դիտարկչի տեղային պահոցում։ Google Maps բացելիս ընտրված հասցեն փոխանցվում է Google-ին։ Մասնավոր հղումն ու հասցեները մի հրապարակեք։ Նախկին մասնավոր հղումը չի փոխվել։

## Օգտագործում և սահմաններ

Ամբողջ օրվա քայլքի/մեքենայի հղումները բաժանված են առավելագույնը 3 միջանկյալ waypoint + նպատակակետ մասերի։ Հանրային տրանսպորտը բացվում է առանձին հատվածներով։ Այցելած/բաց թողնված կետերը հանվում են այդ հղումներից։ Վեր/վար, նշումները և օրվա վերականգնումը պահվում են կայուն id-ներով։

Օդանավակայանի ժամերը չեն վերահաշվարկվում։ `city`-ի առկայության դեպքում ցուցադրվում է քաղաքի timezone-ը, բացակայության դեպքում՝ «տեղական ժամ, քաղաքը նշված չէ»։ Չվերթի depart_local/arrive_local-ը ցուցադրվում են բառացի՝ մեկնման/ժամանման վայրի տեղական ժամ նշումով։ `buffer_min=null`-ը անհայտ է, թվային <120-ը՝ կարմիր։ Տվյալների պիտակները նոր հետազոտության արդյունք չեն։

Առաջին հաջող առցանց բացումից հետո տեքստը, օդանավակայանները և նշումները հասանելի են offline։ Քարտեզի նոր հատվածները, լուսանկարները և Google Maps-ը պահանջում են կապ։ GPS-ը մեկ չափում է, չի պահվում։

Փորձնական էջ՝ [բացել demo](https://rigelarmenia-cell.github.io/europe-trip-2026/?demo=1)։ 2 օր, 10+2 պայմանական կանգառ, 2 տեղափոխություն և 1 պայմանական զգուշության գոտի։ Իրական այցելության առաջարկ չէ։

Հետագա տվյալների թողարկման ժամանակ բարձրացրեք `trip.json.version`-ը, պահպանեք կայուն id-ները։ Այս հանձնումում 05 §3-ի ԱՆՓՈՓՈԽ պահանջը գերադասվել է §6.2-ի հակասող բարձրացման հրահանգից։ Միայն հավելվածի RELEASE-ն է բարձրացվել 0.2.0։
