# Ճամփա · europe-trip-2026

Հայերեն ստատիկ PWA-ի **առաջին կմախք**։ Սա վերջնական ճամփորդական ծրագիր չէ։ Ներառված `trip.json`-ում կա մեկ փորձնական օր և երկու պայմանական կետ։ Գները, ժամերը, լուսանկարները և իրական երթուղիները չեն հորինվել։

## GitHub-ում ստեղծելու քայլերը

1. Բացեք [github.com/new](https://github.com/new) և մուտք գործեք ձեր GitHub հաշիվ։ Գաղտնաբառը կամ մուտքի կոդը chat-ում մի ուղարկեք։
2. **Owner**՝ `rigelarmenia-cell`։ **Repository name**՝ `europe-trip-2026`։ Նշեք **Public**։ Միացրեք **Add a README file**, որ ստեղծվի առաջին ճյուղը։ Սեղմեք **Create repository**։
3. Համակարգչում բացեք `europe-trip-2026.zip`-ը և ընտրեք **Extract All / Извлечь всё**։
4. Repository-ի **Code** էջում ընտրեք **Add file → Upload files**։ Քաշեք բացված պանակի **ներսի ֆայլերն ու ենթապանակները**։ Մի վերբեռնեք ZIP-ը կամ ամբողջ արտաքին պանակը մեկ լրացուցիչ մակարդակով։ `index.html`-ը պետք է հայտնվի repository-ի հենց առաջին մակարդակում։
5. Վերբեռնվում են `index.html`, `styles.css`, `app.js`, `sw.js`, `trip.json`, `manifest.webmanifest`, `.nojekyll`, `lib`, `icons`, `vendor` և փաթեթի փաստաթղթերն ու թեստերը։ `README.md`-ը փոխարինում է նախնական դատարկ README-ին։ Բնօրինակ 00/01/02 ֆայլերը մի վերբեռնեք․ դրանք մասնավոր տվյալներ են պարունակում։
6. **Commit changes** դաշտում գրեք `Add travel PWA skeleton`, ապա սեղմեք **Commit changes**։
7. Բացեք **Settings → Pages**։ **Build and deployment → Source** դաշտում ընտրեք **Deploy from a branch**։
8. **Branch**՝ ընտրեք `main` (կամ այն ճյուղը, որտեղ հենց նոր վերբեռնել եք ֆայլերը), կողքին՝ **/(root)**։ Սեղմեք **Save**։
9. Բացեք **Actions**։ Սպասեք **pages build and deployment** աշխատանքի հաջող ավարտին։ Ձախողման դեպքում բացեք այդ աշխատանքը և կարդացեք սխալը։
10. Վերադարձեք **Settings → Pages**, սեղմեք **Visit site**։ Սպասվող հանրային հասցեն՝ [rigelarmenia-cell.github.io/europe-trip-2026/](https://rigelarmenia-cell.github.io/europe-trip-2026/)։ Այս հասցեն դեռ հրապարակված/ստուգված չի համարվում միայն այն բանի համար, որ գրված է այստեղ։
11. Էջում պետք է երևա **«ՓՈՐՁՆԱԿԱՆ ՏՎՅԱԼ»**, երկու փորձնական կանգառ և քարտեզը։ Սեղմեք առաջին **«Գնալ այստեղ»** կոճակը՝ միայն հղման աշխատանքը փորձելու համար։ Սա իրական այցելության առաջարկ չէ։
12. Բացեք հանրային հղումը հեռախոսում և կատարեք ստորև նշված տեղադրումն ու ստուգումները։

ՀԱՍՏԱՏՎԱԾ՝ GitHub-ի պաշտոնական ընթացակարգով հնարավոր է հրապարակել ճյուղի արմատից։ Ստուգված՝ 17.10.2026։ [GitHub Pages-ի պաշտոնական հրահանգ](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)։

## Հեռախոսում տեղադրելը

- **Android / Chrome**՝ բացեք HTTPS հղումը → ⋮ → **Install app** կամ **Add to Home screen**։ Հավելվածի ներսի «Տեղադրել ծրագիրը» կոճակը ցուցադրվում է միայն այն դեպքում, երբ դիտարկիչը տրամադրում է այդ հնարավորությունը։ Այն անմիջապես երևալը երաշխավորված չէ։
- **iPhone / Safari**՝ բացեք հղումը → **Share → Add to Home Screen** → եթե կա **Open as Web App**, միացրեք → **Add**։ Որոշ տարբերակներում Share-ը հասանելի է էջի մենյուից։
- Բացեք նոր պատկերակից։ Բացեք կազմակերպչի **մասնավոր հղումը** և ստուգեք «Տուն»-ը հենց այն պատուհանում, որտեղ ծրագիրն օգտագործելու եք։ Safari-ն և գլխավոր էկրանի ծրագիրը կարող են առանձին պահոց ունենալ. իրական iPhone-ում այս փոխանցումը **ՉՍՏՈՒԳՎԱԾ** է։ Եթե պատկերակից բացված ծրագրում հասցեն չկա, ժամանակավորապես օգտագործեք Safari-ի այն պատուհանը, որտեղ մասնավոր հղումը բացել եք, և հաղորդեք խնդիրը։
- «Իմ դիրքը» → կարդացեք բացատրությունը → թույլատրեք հարցումը։ Մերժելու դեպքում պլանը շարունակում է աշխատել։ Դիրքը մեկ չափում է, շարժվելուց հետո սեղմեք «Թարմացնել դիրքը»։
- Առաջին բացումը կատարեք ինտերնետով, սպասեք ներքևի պահպանման հաղորդագրությանը։ Հետո անջատեք ինտերնետը, փակեք և վերաբացեք ծրագիրը։ Տեքստն ու պլանը պետք է մնան։ Քարտեզի նոր հատվածները, լուսանկարները և Google Maps-ը պահանջում են ինտերնետ։

ՀԱՍՏԱՏՎԱԾ՝ պաշտոնական տեղադրման հրահանգներ, ստուգված՝ 17.10.2026։ [Chrome/web.dev](https://web.dev/articles/install-criteria), [Apple](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios)։ Իրական սարքերում այս ծրագրի տեղադրումը՝ **ՉՍՏՈՒԳՎԱԾ**։

## Մասնավոր հղումը

Պատրաստի մասնավոր հղումը տրվում է **միայն chat-ում**։ Repository-ն պարունակում է միայն այն կարդալու մեխանիզմը։ Fragment-ը սերվերին չի ուղարկվում, բայց հասցեները կարող է կարդալ հղումն ունեցող ցանկացած մարդ։ Այն գաղտնագրված չէ։ Մի տեղադրեք README-ում, issue-ում, հանրային հաղորդագրությունում կամ screenshot-ում։

Հղումը բացելիս հասցեները պահվում են տվյալ դիտարկչի տեղային պահոցում, իսկ հասցեների մասը հեռացվում է հասցեի տողից։ «Տուն»-ը սեղմելիս ընտրված հասցեն փոխանցվում է Google Maps-ին։ GPS-ի տվյալը չենք պահում։ Քարտեզը ստանում է տվյալ դիտարկչի ցուցադրվող տարածքի tile հարցումները։

## Հետագա թարմացում

- **Միայն ճամփորդական տվյալներ**՝ փոխարինեք միայն `trip.json`-ը և բարձրացրեք `version`-ը՝ `YYYY-MM-DD-N` ձևով։ Պահպանեք 01-ի 5-րդ գլխի կառուցվածքը և կայուն id-ները։ Անհայտը՝ null/դատարկ։ Հեռացրեք բոլոր փորձնական կետերն ու նշումները իրական տվյալներով փոխարինելիս։
- Ծրագիրը նոր ֆայլը ստուգում է բացվելիս, պատուհան վերադառնալիս, կապը վերականգնվելիս և «Ստուգել տվյալների թարմացումը» սեղմելիս։ Նորի դեպքում առաջարկում է թարմացնել։ Անվավեր JSON-ը չի փոխարինում վերջին վավեր տարբերակին։
- **Ծրագրի կոդ**՝ վերբեռնեք փոփոխված ֆայլերը և `sw.js`-ում բարձրացրեք `RELEASE`-ը։ Եթե նոր ֆայլ կա, ավելացրեք `FILES` ցանկում։ Օգտատերը կտեսնի ծրագրի նոր տարբերակի առաջարկը։
- Տեղային հասցեների բանալիները չեն ջնջվում։ Կանգառների նշումները և հերթականության փոփոխությունը դեռ հաջորդ փուլում են։

## Այս փուլի սահմանը

Գրված են՝ քաղաք/օր, կանգառների քարտեր, աղբյուրների և լուսանկարների տեղեր, քարտեզ, GPS, մեկ կանգառի նավիգացիա, մասնավոր տան հասցեի ընդունում և կայարանի պահուստային տարբերակ, տոմսերի և օդանավակայանի տվյալների ընթերցման հիմք, տարբերակի թարմացում, offline տեքստ, manifest և տեղադրման ստուգաթերթ։

Հաջորդ փուլում մնում են՝ ամբողջ օրվա Google Maps հղումները և բաժանումը, այցելել/բաց թողնել/վերադասավորել/վերականգնել, զգուշության շերտը, օդանավակայանի ժամանակների ամբողջական վերլուծությունն ու 120 րոպեի զգուշացումը, 9 իրական օրերն ու 6 տեղափոխությունները, իրական Fold 4 և iPhone ընդունումը։ Պահանջները չեն հանվել։ KML-ը լրացուցիչ է։

Կառուցվածքային բաց հարց՝ `airport_transfers`-ը չունի քաղաքի/timezone-ի բացահայտ դաշտ։ `flights`-ի և տեղական ժամերի տարբեր ձևաչափերը պետք է համաձայնեցնել իրական trip.json-ը ստանալիս՝ առանց սխեմայի լուռ փոփոխության։

02-ի Բ4-ի համաձայն «Գնալ այստեղ»-ի սկզբնական ռեժիմը վերցվում է `to_next.mode`-ից։ Քանի որ դա դեպի հաջորդ կետ ճանապարհի դաշտն է, քարտում ռեժիմը տեսանելի և փոփոխելի է, իսկ քարտեզի բացվող պատուհանում առաջարկվում են բացահայտ քայլք/տրանսպորտ/մեքենա հղումներ։ Ծրագիրը չի պնդում, թե սկզբնական ընտրությունը հաշվարկված լավագույն երթուղի է։

## Տեղային ստուգում

Node.js 22-ով՝ `npm test`, ապա `npm start`։ Բացեք տերմինալում գրված `http://127.0.0.1:4173/travel/` հասցեն։ Հեռախոսը չի կարող բացել համակարգչի այս loopback հասցեն։ Իրական հեռախոսների համար օգտագործեք GitHub Pages HTTPS-ը։ Ֆայլը double-click-ով բացելիս service worker-ը չի աշխատի։

Արտադրական միակ կախվածությունը Leaflet 1.9.4-ն է՝ `vendor/leaflet` պանակում։ Հավաքման քայլ, հաշիվ, սերվերային ծրագիր, վճարովի բանալի կամ API չկա։ Քարտեզը չի գծում կանգառների միջև ուղիղ գծեր։ OSM tile-երը service worker-ում չեն պահվում/նախապես ներբեռնվում. դիտարկիչն օգտագործում է սովորական HTTP cache-ը։
